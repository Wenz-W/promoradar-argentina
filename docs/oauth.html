Conectar Mercado Libre

Esta página auxilia na autorização de uma aplicação própria. Não envia credenciais para servidores do PromoRadar. A troca do código por tokens acontece no GitHub Actions.

1. Configure o aplicativo e o GitHub

Cadastre este endereço HTTPS como Redirect URI no Mercado Libre DevCenter, exatamente como aparece:

Antes de autorizar, crie no GitHub Actions Secrets: MELI_CLIENT_ID, MELI_CLIENT_SECRET e DATA_FERNET_KEY. O App ID não é secreto; o Client Secret e a chave são.

Guarde a chave exclusivamente no GitHub Secret DATA_FERNET_KEY. Se a perder, não será possível abrir o cofre criptografado. Esta página não a salva.

2. Autorize a sua conta

Se PKCE estiver habilitado na aplicação, marque esta opção. Será gerado um code_verifier, que deverá ser guardado no GitHub Secret MELI_CODE_VERIFIER.

3. Código retornado pelo Mercado Libre

Depois de configurar os Secrets, execute Actions → Conectar Mercado Libre (OAuth seguro) → Run workflow na branch main.

O código de autorização é temporário e de uso único. Não o compartilhe em chats, issues ou commits. Apague os Secrets temporários MELI_AUTH_CODE e MELI_CODE_VERIFIER depois do sucesso.

Fonte: Autenticación y Autorización — Mercado Libre. O acesso à API de pesquisa depende das permissões concedidas pelo Mercado Libre.
